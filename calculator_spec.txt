0. How This Document Started
The idea began from a live birth/death counter app.
That led to a broader question: which "build once, earn
later" web tools are actually worth building in 2026?
The research below traces that question from generic
tools down to a specific, defensible niche.
Conclusion up front: Generic calculators and
counters are dead ends. The printing/packaging
vertical — specifically an India-localized version of it —
is the only opening worth pursuing, and that window is
closing within 12–18 months.

1. Where The Idea Started — Live
Counters
What they are
Population clocks / live birth-death counters. Main
examples: Worldometer, worldbirthsanddeaths.com,
LiveHumans, GlobalStats Live.
How they actually work
No government or international body collects
population data in real time.
The counter is a calculated projection, not a tally.
Base = UN estimates (census, birth/death
registration, surveys). Fertility and mortality rates
are applied and the number is incremented
forward.
A given country's underlying data averages ~2
years old.
Global rates roughly: 4.4 births/sec, 1.9 deaths/sec
→ net ~2.5 people/sec, ~200,000+/day.
Technical build
Trivially simple: baseline number + timestamp + rate +
setInterval . Fully client-side, no server needed.
Verdict — DO NOT BUILD


--- Page 3 ---
Worldometer has been running since 2004
(Dadax Ltd), available in 31 languages, monetized
via display advertising. Its domain authority is
untouchable.
Novelty traffic only. Visitors stay ~30 seconds,
view one page. Low pageviews/visit = low RPM.
Display ad RPM is typically $0.50–$5 per 1000
pageviews. Indian traffic sits at the very bottom of
that range. 100,000 Indian pageviews ≈ ₹3,000–
8,000/month.
Thin content creates AdSense approval problems.

6. Core Formulas (Verify Before
Coding)
These came from an uploaded report with no
cited source. Validate every one against your


--- Page 17 ---
own production data at PGPL before shipping. A
wrong formula in a costing tool destroys
credibility permanently.
A. Paper roll length from outer diameter
Length (m) = [(D² − d²) × 0.785] / 
[Thickness (µm) / 1000]
D = outer roll diameter (mm), d = core outer diameter
(mm), Thickness = substrate caliper (microns)
B. Flexo die repeat & gear teeth (1/8" CP standard)
Cylinder Repeat (mm) = Gear Teeth (Z) × 
3.175
Number of Cavities   = Repeat (mm) / (Label 
Height + Gap mm)
Standard flexographic tooling runs on 1/8" circular
pitch = 3.175 mm per tooth.
C. Corrugated 3-ply / 5-ply weight & cost
Total Sheet Area (m²) = [(2L + 2W + Joint) 
× (H + Top/Bottom Flaps)] / 1,000,000
Total Box Weight (g)  = Area (m²) × 
[GSM_top + (GSM_flute × Flute_factor)
                                      + 
GSM_liner + Gum_allowance]

conversion cost per kg.
